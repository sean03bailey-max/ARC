The Web App

ARC is the central digital workspace for the Ateneo de Naga College Red Cross Youth Council. It unifies three purpose-built modules into a single platform:

NEXUS — Resource Board

A visual QR-code board for sharing links, documents, and resources. Upload QR images, add rich-text descriptions, organize cards, and export boards as images for offline use.

TRACKER — Scheduler

External scheduling system (red-cross-scheduler.vercel.app) for managing volunteer shifts, event timetables, and availability tracking.

CORE — Deliverables Tracker

A structured monthly tracker for officer and committee deliverables. Manage status (Not Started → In Progress → Completed), deadlines, and remarks with real-time multi-user sync.

Click any module button below to navigate. Use the Unlock button to access editing features on NEXUS and CORE.
