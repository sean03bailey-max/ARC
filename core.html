How to Use CORE

Getting Started

CORE is the Officers' Deliverables System — a structured monthly tracker for committee commitments, progress, and deadlines. All edits sync in real-time across all officers.

Tracker Layout

  • Officer / Committee — Role or committee name (color-coded).
  • Deliverable — Task description (supports lists, rich text).
  • Status — Dropdown: Not Started, Blocked, In Progress, Completed, NONE.
  • Deadline — Target date for each deliverable item.
  • Additional Remarks — Notes, blockers, or context.

Editing & Workflow

  • Click Unlock (top-right) and enter the password to enable editing.
  • When unlocked, click any cell to edit. Press Enter to save, Esc to cancel.
  • Use the formatting toolbar (top of table) for Bold, Italic, Underline, lists, etc.
  • Each deliverable can have multiple items — add list items to create stacked status/deadline/remarks rows automatically.
  • Click Save image to export the entire tracker as a PNG.

Adding & Removing Rows

  • + Add Row — Adds a new committee row (cycles through color palette).
  • − Remove Row — Deletes the last custom row.
  • Built-in officer rows cannot be removed.

Keyboard Shortcuts

  • Esc — Close modals, cancel editing
  • Enter in cell — Save and move to next
  • Tab — Navigate between cells
  • Ctrl+B / I / U — Bold / Italic / Underline (when toolbar active)

Data Persistence

All changes save automatically to the shared backend. The Synced pill in the header shows sync status. The Month, Last updated, and Updated by fields are editable for record-keeping.
